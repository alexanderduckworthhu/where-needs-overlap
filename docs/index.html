Where Needs Overlap

A country-level dashboard showing where acute food insecurity, hosted displacement, and under-5 mortality coincide.

This is a static project page hosted on GitHub Pages. Prefer the hosted live demo when it is available; if Streamlit/Render is asleep or unreachable, use this page and run the app locally from the repository.

Live demo (Streamlit) ↗ Code on GitHub ↗ Portfolio ↗

Status: Portfolio learning project, not an operational product

Challenge & trade-offs

  • Joined three live public APIs (HDX/IPC, UNHCR, WHO GHO) on ISO3 with documented definitions.
  • Deliberately no machine learning forecasting: the tool frames one decision question instead of unverifiable crisis prediction.

Impact

  • Surfaced 3 dual-pressure countries (Sudan, Ethiopia, Chad) above both focus-set medians across ~48.6M people in IPC Phase 3+.
  • Coverage gaps flagged explicitly rather than silently imputed.
