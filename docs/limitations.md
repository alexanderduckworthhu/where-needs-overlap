# Limitations

These are features of the data, not personal failures. Name them in interviews.

1. **National aggregates hide hotspots.** A country average can look "moderate" while one region is in catastrophe. This app cannot replace subnational IPC maps.
2. **IPC coverage is uneven.** Not every country has a current national Phase 3+ row in the HDX extract (e.g. South Sudan in the build used for the case study). Missing = unmeasured here, not zero hunger.
3. **Displacement definitions matter.** We use people *hosted* (country of asylum). Origin-based refugee counts tell a different story.
4. **WHO under-5 mortality is lagged.** Treat U5MR as structural risk context, not a real-time pulse.
5. **Compound score is illustrative.** Z-score blending is a conversation aid, not an official severity index and not for targeting.
6. **Trends are partial.** Country deep-dive plots UNHCR and WHO history; IPC is assessment-based and not drawn as a false smooth time series.
7. **This is not operational.** Do not use this portfolio app alone for resource allocation or advocacy claims about named communities.
